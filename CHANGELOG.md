# Changelog

## 1.2.0 (2025-11-03)

-   Updated word list (`+215` words).
-   Score calculations (tile score, position score, combined score). Contribution by [@nateify](https://github.com/nateify).
-   New controls:
    - `del` to clear cell, `backspace` to clear cell and move back, `esc` to clear grid. Contribution by [@nateify](https://github.com/nateify).
    - Click anywhere empty to focus the first the first empty cell. Contribution by [@nateify](https://github.com/nateify).
    - Hotkey reference section.
-   Underlined wildcard usages. Contribution by [@nateify](https://github.com/nateify).
-   Dark theme.
-   Settings panel, with theme selection and score display toggles.

## 1.1.0 (2025-07-23)

-   Updated word list (`+337` words).
-   Collapsible word list subsections. Suggested by Dominic on Steam.
-   Automatic "last updated" page footer. Contribution by [@tampueroc](https://github.com/tampueroc).
-   Wildcard support. Suggested by Viralsiren on Steam.

## 1.0.0 (2025-07-16)

-   Initial release
-   Basic letter grid input
-   Bonus tile locking/unlocking
-   Word list compression
-   Word list filtering and sorting
-   Result filtering by prefix, suffix, infix
